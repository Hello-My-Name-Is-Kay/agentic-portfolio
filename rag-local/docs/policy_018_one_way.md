# One-Way Rentals

## Definition
A one-way rental allows the customer to pick up the vehicle at one location and return it to a different location.

## Availability
One-way rentals are available for most vehicle categories. Some restrictions may apply during peak periods or for certain vehicle categories.

## Fees
- One-way rentals within the same city: no additional fee.
- One-way rentals between cities in the same region: $50 fee.
- One-way rentals between regions: $100 fee.
- One-way rentals involving different countries: not available.

## Drop-off Locations
Vehicles dropped off at a different location will be subject to a return inspection at that location. The customer must return keys and complete the return paperwork at the drop-off location.
